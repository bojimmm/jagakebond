# Closer maps and visible plot boundaries (0.2.3.7)

The main map and photo-location editor allow display zoom22 instead of19.
OpenStreetMap native tiles stay capped at19; existing Esri imagery stays capped
at18. Leaflet scales those existing tiles at closer display zoom, so this does
not create extra image detail or make precise image coordinates surveyed GPS.
Location-editor plot fitting allows21 rather than17; users can continue to22.

Shared magenta (#c026d3) edges have a white/dark halo, light magenta transparent
fill and three-pixel default width. Selected/edited boundaries use five-pixel
solid edges and stronger fill; other plots are dashed. Saved plots, Geoman
preview/drawing/editing, GPS tracing and the location editor share this scheme.
Plant health markers keep their severity colors. Selecting another editor plot
updates its highlight. Styling and zoom do not change saved geometry/locations.

Leaflet1.9.4 documentation confirms maxNativeZoom automatically scales tiles
above the native source level:
https://leafletjs.com/reference.html#gridlayer-maxnativezoom

prefetch/offline archive feature added. Existing SW excludes cross-origin tiles:
https://operations.osmfoundation.org/policies/tiles/
