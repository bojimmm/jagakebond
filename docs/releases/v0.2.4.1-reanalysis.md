# Reanalysis, concise diagnoses and camera sizing (0.2.4.1)

> **Release** 0.2.4.1 · **Status** shipped

Reanalysis now uses the clean original photo stored by the server. The client
posts only an empty request to `/api/records/{record_id}/reanalyze`; it cannot
send a stamped image, diagnosis, coordinates or replacement photo. The backend
checks ownership, an active account, AI provenance, photo availability, file
size, record version, queue admission and duplicate active jobs before it
queues the work. Each queued request is audited. The Android bridge permits only this record-scoped POST path, without query parameters or a client-supplied file.

A successful reanalysis updates the existing record in one database
transaction. It preserves the record ID, plant and farm links, coordinates,
clean photo reference, source, original capture time, creation time and other
non-diagnosis metadata. The previous hypothesis is copied to
`previousCondition` and is labelled in the UI as an unconfirmed comparison.
Failed or rejected jobs leave the prior diagnosis unchanged.

The full-analysis dialog now has an `Analisis ulang` button for saved AI records
whose server photo is available. It disables while preparing or polling,
reports queue progress, refreshes the same record after completion and keeps
the current analysis visible if the new run fails.

Displayed diagnosis labels now resolve to one or two substantive words, for
example `Ulat`, `Antraknosa`, `Mosaik`, `Hama penggerek` or
`Kekurangan Kalium`. The full dialog uses the proper heading `Dugaan Hama /
Penyakit`, and the chemical disclosure uses `Tinjau Opsi Kimia / Pupuk`.
Checkbox controls align with the first line of their explanations, and the
Riwayat tree-card camera control is 56 x 56 px with a 26 px icon to match the
card height.

Release 0.2.4.1 / Android versionCode 29 / cache jk-v34 / protocol 2.1.0 /
schema 10. No migration, signing change, DNS change or farmer-data mutation.
Google remains enabled with the existing configuration. Chemical references
remain behind the accepted limitation terms and use the analysis-derived
