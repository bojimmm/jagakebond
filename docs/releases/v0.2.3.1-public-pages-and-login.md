> **Release** 0.2.3.1 · **Status** shipped

Owner request (2026-10-29): create privacy/terms pages for Google setup, fix black

## Result

- White desktop split layout with a farm welcome panel, transparent illustrative
  farmer artwork, example record cards, and a simple sign-in form.
- Mobile prioritizes the form and avoids downloading decorative desktop artwork.
- A password reveal button, actual admin-reset help, and registration visibility
  based on a public capability endpoint. Closed registration no longer offers a
  button that immediately fails.
- `/privacy.html` and `/terms.html` are public, responsive, and linked before login
  and in the account dialog. `/privacy` and `/terms` are aliases. Legal pages use
  the approved contact email, document actual data flows/retention, and distinguish
  deleting local data from deleting server records and backup copies.
- Public `/api/auth/options` reveals only whether password registration is open.

The old crop WebP images were RGB with black background pixels and no alpha.
The redesigned landing does not use them. New `img/landing-farmer.webp` is RGBA
with real zero-alpha corners, optimized to about 302 KiB from built-in ImageGen.
It is a fictional illustration, not a customer portrait or real farmer data.
It is cached only when requested, rather than in the mandatory phone shell.

2.1.0. The signing key/configuration stay unchanged. 0.2.3.0 is already frozen,
so it is not overwritten. The release includes its Google security fixes;
