# Analysis dialog header (0.2.4.7)

> **Release** 0.2.4.7 · **Status** shipped

Lihat analisis dan pencegahan opened with a text button labelled **Tutup** and,
below 480 px, the crop species title was aligned to the top of the header row.
On a phone that pushed the species name above the close control instead of
centring it on the same line.

The header now keeps `align-items:center` at every width, the title carries a
stable `line-height:1.35`, and the action group never shrinks. The close
control is an icon-only `.btn.btn-quiet.btn-icon.btn-sm` that renders the Lucide
`x` icon at 44x44 px. `Lucide.createIcons()` runs once after the dialog is
attached to the body so the SVG is present before the dialog is shown.

The accessible name is unchanged: `aria-label="Tutup analisis"` plus
`title="Tutup analisis"`, so screen readers, the existing browser suites and the
Escape/back handling keep working. Clicking the X, pressing Escape and pressing
Enter on the focused control all close the dialog and restore focus to the
trigger.

Release 0.2.4.7 / Android versionCode 35 / cache `jk-v41` / protocol 2.1.0 /
schema 10. `assessment-ui.js?v=9` and `assessment.css?v=7`. No database,
API-protocol, Google, signing, DNS or farmer-data changes. Install over the
existing Android app; never uninstall or clear app data.

## Re-analysis progress

Analisis ulang now opens the same visible progress surface used by a new photo. It shows the crop and original photo, preparation, the server-reported queue position and worker stage, a meter, four stages (Foto asli, Antrean, Analisis, Hasil), retry feedback, and the protection notice. The dialog can be hidden without cancelling the job. On completion it offers **Lihat hasil terbaru** and updates the original history record in place.
