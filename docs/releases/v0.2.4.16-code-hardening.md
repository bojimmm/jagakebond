# Code hardening: audit F10-F14

> **Release** 0.2.4.16 · **Status** shipped

Release candidate: 0.2.4.16 / Android versionCode 44 / cache jk-v50. Built on live 0.2.4.15. No visible change intended.

- **F11, strict CSP:** every inline `on*=` attribute (106 in index.html, 27 built by app.js) is now `data-act` + `data-args` (JSON; `$this`/`$event` placeholders; `data-on` for change/input; `data-stop`). One delegated listener in `actions.js` calls the named global function and, like inline handlers did, lets outer actions follow unless propagation was stopped. The field-app CSP is now `script-src 'self'` (and `'self' https://accounts.google.com/gsi/client` with Google sign-in): no inline script can run, so an escaping mistake can no longer become script execution.
- **F10, no more re-assigned globals:** `workflow-ui.js` used to re-assign nine `app.js`/`scan-flow.js` functions. Wrappers became `JagaHooks` registrations (`menu-shown`, `account-reset`, `before-live-camera`, `data-refreshed`, `telemetry-shown`) run by the owning function; full replacements (`saveRecord`, `updateOfflineDraftCount`, `downloadStampedPhoto`) are plain declarations in `workflow-ui.js` and the dead `app.js` copies are gone; the identity wrapper of `openViewerForRecord` is removed.
- **F12/F13, tokens:** colours equal to a `ui-kit.css` token use it (raw hex in styles/assessment/tour 315 → 183; the rest are one-off shades); every page-level z-index has a named token with the same value (`--jk-z-map-controls` … `--jk-z-workflow`).
- **F14, motion:** the upload/analysis/confidence fills animate `transform: scaleX()` instead of `width`. The desktop sidebar's 0.2 s grid transition is kept (desktop only).

Tests: review/browser-tools/hardening-0256.cjs (in the runner, 83 suites); web-0220.cjs now runs under the strict CSP read from backend/app.py.
