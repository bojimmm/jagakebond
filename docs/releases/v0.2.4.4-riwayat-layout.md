# Full-width desktop Riwayat layout (0.2.4.4)

> **Release** 0.2.4.4 · **Status** shipped

Desktop Riwayat now uses one content column. The processing strip, view tabs,
search field, status filters and crop cards stack in that order across the full
main-content width. A tree timeline still replaces the filter/list view in the
same full-width column.

The phone layout keeps its existing flex-column order and touch behaviour. No
API, schema, Google, DNS, signing or farmer-data changes are included.
Reanalysis continues to expose only the immediately previous hypothesis as an
unconfirmed comparison after a successful changed result.

Release 0.2.4.4 / Android versionCode 32 / cache `jk-v37` / protocol 2.1.0 /
schema 10.
