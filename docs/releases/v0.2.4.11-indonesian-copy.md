# Indonesian copy pass and small display fixes

> **Release** 0.2.4.11 · **Status** shipped

Release candidate: 0.2.4.11 / Android versionCode 39 / cache jk-v45. Built on the 0.2.4.10 candidate.

- KBBI wording: "analisa/dianalisa/menganalisa" becomes "analisis/dianalisis/menganalisis" everywhere a farmer or admin reads it (button "Analisis", "N sedang dianalisis", header chip "N dianalisis").
- Admin console: "berkas yatim" becomes "foto tanpa catatan"; "sandi" becomes "kata sandi"; Google requests read "Permintaan masuk"; the fast-model settings no longer describe the "mode Cepat" choice removed in 0.2.4.7.
- Field app: "Edit" becomes "Ubah" for plots; "m MSL" becomes "m dpl"; "Snapshot terakhir" becomes "Data terakhir"; "cap geotag" becomes "cap lokasi"; "pin" becomes "titik"; "minimal 8 karakter"; "Contoh:" instead of "cth:"; one-character ellipsis in re-analysis progress.
- Server messages a farmer can see use words, not field names (for example "Status pengamatan tidak valid." instead of "observedSeverity tidak valid"); "Silakan masuk" instead of "Silakan login".
- Every toast and error box that showed a raw error now goes through userMessage(), so English platform errors (Android bridge, browser) are replaced by Bahasa text.
- Riwayat strip: a photo the server refused counts as "N gagal", never "belum terkirim", and "Kirim sekarang" only appears when something can be sent.
- Daily summary no longer says "Sehat — sehat".
- Re-analysis dialog: step labels are 13 px on phones, the last step turns done at 100 %, and the two buttons wrap instead of clipping "Lihat hasil terbaru" at 360-375 px.
- Plot area: hectares use thousand separators; the drawing bar switches to ha above 1 ha.

Not built, regression-tested, or deployed yet when written. Production remains 0.2.4.9.
