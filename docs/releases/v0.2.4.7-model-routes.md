# Model routes for any provider (0.2.4.7)

> **Release** 0.2.4.7 · **Status** shipped

The admin console used to reject any model route containing `-local`:

> Model triase: rute 'gemma-*-local' dilarang - rute itu diam-diam menghasilkan
> model non-Gemma. Gunakan rute langsung gemini/gemma-*.

That rule came from the 2.1 PRD, which required Gemma for both stages and treated
a silent non-Gemma fallback as a defect. The operator now wants to point the
worker at models from other providers, so the rule is obsolete.

What changed:

- `settings_store.validate()` accepts any route for the four model keys
  (`GEMINI_TRIAGE_MODEL`, `GEMINI_DIAGNOSE_MODEL`, `GEMINI_TRIAGE_MODEL_FAST`,
  `GEMINI_DIAGNOSE_MODEL_FAST`), including `gemma-*-local` combos,
  `openai/gpt-4o-mini`, `qwen/...`, `deepseek/...` and plain 9Router combo names.
- The only shape check left is "one route, no spaces", so a pasted sentence or
  two concatenated names cannot be saved silently. Empty values still mean
  "leave the stored value alone", and control characters and the 120-character
  limit are unchanged.
- The console help text no longer tells the operator to use only
  `gemini/gemma-*`. It now says any router route is valid and names a
  non-Gemini example.
- `PRD.md` section 7 and `BUILD-INSTRUCTIONS.md` record the new policy so the
  documents no longer contradict the console.

Routing is unchanged: the worker reads the four values through
`/api/worker/config`, `models_for(job)` picks the normal or Cepat pair, and
9Router expands whatever alias it is given. The defaults stay on
`gemini/gemma-4-26b-a4b-it` / `gemini/gemma-4-31b-it` for normal mode and
`jagakebond-fast` for mode Cepat, so nothing changes until the operator saves a
different route.

Operator steps after the upgrade:

1. Buka Konsol Admin -> Setelan -> Router / model.
2. Isi Model triase dan Model diagnosis (dan pasangan mode Cepat bila dipakai)
   dengan nama rute yang ada di 9Router.
3. Pakai "Uji router" untuk memastikan rute itu ditemukan sebelum disimpan;
   hasil uji menampilkan nama yang dicari beserta status ditemukan/tidak.
4. Simpan. Tidak perlu mengubah `.env` atau me-restart layanan; worker membaca
   konfigurasi dari `/api/worker/config`.

Saving a router URL or key still requires the admin password again; model route
values do not, because they are not secrets.

## Optional land-condition form

The Tinjau Opsi Kimia / Pupuk land-condition fields are now optional. The six
text inputs and the soil/hara field no longer carry the HTML `required`
attribute, and the `/api/recommendations` endpoint accepts blank values after
the terms checkbox is accepted. The API still rejects non-text values and
values longer than 240 characters. Empty fields produce the same honest
coverage/no-data notes instead of blocking the request.

## Assessment wording

The full Lihat Analisis dan Pencegahan view no longer repeats `Dugaan sebelum
analisis ulang`. The previous hypothesis remains stored and is still shown in
the photo viewer/detail context, but it is omitted from the analysis dialog's
summary. The nutrition section heading is now `Kebutuhan Unsur Hara`.
