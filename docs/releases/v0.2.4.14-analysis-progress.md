# Analysis progress for photos in Riwayat

> **Release** 0.2.4.14 · **Status** shipped

Release candidate: 0.2.4.14 / Android versionCode 42 / cache jk-v48. Built on live 0.2.4.13.

- Riwayat "N sedang dianalisis": tapping a photo that is being analysed opens the same progress dialog as Analisis ulang, titled "Analisis foto", with the bar and the steps Terkirim · Antrean · Analisis · Hasil. It follows the job's real server stages (queue position, triage, diagnosis). When the job finishes it saves the result to Riwayat and offers "Lihat hasil terbaru"; a refused photo shows the reason. Closing the dialog does not stop the analysis.
- The row's text block is the button (no nested buttons), labelled "Lihat kemajuan analisis: <tanaman>", with the hint "Ketuk untuk melihat kemajuan"; the thumbnail opens it too.
- The strip's down arrow sits in the middle of the strip head; the summary stays left.
- Fixed: the progress value was written to a non-existent element (#reanalysis-progress), so the bar's accessible value never changed; it now updates #reanalysis-meter.

Tests: riwayat-0250.cjs (arrow position, progress dialog through queued, claimed and refused states).
