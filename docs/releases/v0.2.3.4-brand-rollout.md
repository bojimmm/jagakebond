# Brand rollout 0.2.3.4

> **Release** 0.2.3.4 · **Status** shipped

Uses the owner's supplied Minimalist Green Sprout Logo.png unchanged as the
source (SHA25626a9d10855da76cd5e0b8adbc73d18852f785070310966286eeb58d0025aadc1).
The original RGBA file has real transparency. app/make_icons.py builds all web
and Android assets from it by trimming transparent margins and resizing while
preserving aspect ratio. No generated reinterpretation of the supplied mark.

All 33 previous brand rasters are replaced: seven web/master icons, fifteen
Android launcher variants and eleven splash images. Apple/maskable icons have
white opaque backgrounds; normal/foreground marks keep real alpha. Android's
old scaffold foreground/background vectors now reference the current mark/white.
The launch theme explicitly uses the new foreground on modern Android.

The website header/sidebar/login, admin login/console, public legal headers,
favicons, PWA and Apple icons use the new artwork. Admin's JK tiles are replaced.
Icon URLs and the manifest link are versioned to refresh browser/install caches.
The PWA ID/start URL and Android package/signing identity remain stable.
Decorative leaf symbols and farm placeholders are UI icons, not brand marks.

Includes all FIELD-0233 fixes. Candidate0.2.3.3 passed65 suites and was packaged
and staged, but never executed or deployed; it stays immutable. This release
deploys directly from live0.2.3.2. Required final66 suites, unchanged source,
Android build/signer/assets, and ten fresh-extraction checks. Cachejk-v27,
versionCode22, schema10, protocol2.1.0. Google remains disabled.
