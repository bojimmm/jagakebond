# 0.2.4.18 — Edit plant status and observed pest/disease

Owner request (2026-11-04): expand **Ubah data tanaman** so a farmer can edit the photo's status, suspected disease and suspected pest. Avoid the word “kartu” in plot advice and explain how to open a plant's recommendation.

## Farmer-facing behavior

- The edit form can change status (Kritis, Waspada, Sehat), suspected disease and suspected pest, alongside the existing species, date and location corrections.
- Status and pest/disease edits apply to the selected photo. Other photos keep their own historical observations; species correction can still be applied to the whole plant.
- The short issue label used across history, map details and plot summaries follows the farmer's entered pest/disease. The structured AI analysis remains stored and is identified as AI-written in the full analysis view.
- Clearing both suspected-problem fields removes the old short label from the card; the AI analysis remains available in the detailed view.
- Plot advice says to open the plant from Riwayat to view its recommended action, instead of referring to a “kartu”.

## Storage

- AI records store the farmer's status in `observedSeverity` without replacing the model result; manual records update their own status.
- `observedProblems` stores the farmer's disease and pest labels in `extra_json`; no schema migration is needed.
- The API validates both short labels and preserves all other `extra_json` values, including location and existing correction metadata.
- Release 0.2.4.18 uses Android versionCode 46, web shell cache `jk-v52`, and refreshed query keys for changed frontend assets.

## Release status

Source changes only. Build, regression run, packaging and deployment remain pending.
