# First-use guide and simpler navigation (0.2.3.9)

A five-step Indonesian guide introduces Beranda, Kamera, full structured
analysis, Peta/petak and Riwayat/follow-up/offline drafts. New and existing
accounts receive it after sign-in once on each device/browser. Completion or
explicit skip/Escape/Android back is remembered per account and guide version
in localStorage. Replay is available in Akun > Panduan penggunaan. It makes no
API writes, opens no camera, changes no screen or saved data, and asks for no
permissions. Storage failure falls back to session memory. Another device may
show the guide again. Account reset closes it and cancels delayed work without
marking the next account complete. Automatic display waits for capture/dialogs.

The accessible modal uses existing focus trapping, inert background and Android
back handling, progress, back/next and skip. Content scrolls independently of
the footer; controls fit narrow phones and short landscape layouts. All copy
and sample cards are static tutorial illustrations, never fabricated user data.

Map detail has Foto lagi followed by a two-column row: Lihat analisis lengkap
beside Lihat riwayat. Legacy records lacking assessment retain a full-width
history action. Beranda removes only the duplicate photo/map shortcuts under
location; bottom/desktop navigation and the empty-state camera action remain.
Desktop location and summary expand to fill the freed width.
